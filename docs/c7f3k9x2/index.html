Получить конфигурацию

Один файл — одно устройство. Нажмите кнопку: страница возьмёт свободный конфиг и скачает его. Если раздаёте доступ, нажимайте заново для каждого человека.

Скачать конфигурацию файл .conf, ключи уже внутри

Как поставить на iPhone

Скачайте файл → «Загрузить» в Safari → откройте WireGuard → «+» → «Импорт из файла или архива» → выберите файл в «Загрузках» → «Сохранить» → включите переключатель.

Если файл открылся текстом — нажмите «Поделиться» → «Сохранить в Файлы», окончание должно остаться .conf.

Один файл — одному человеку

В файлах ключи доступа. Не выкладывайте их в общий чат и не пересылайте ссылку на эту страницу: пусть каждый получает свой файл здесь.
