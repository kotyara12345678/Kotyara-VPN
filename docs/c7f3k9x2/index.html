Конфигурации

Каждый файл — это одно устройство. Скачивайте по одному: архив с телефона распаковывается неправильно и файлы теряют окончание .conf.

Как поставить на iPhone

Скачайте файл по своей ссылке → «Загрузить» в Safari → откройте приложение WireGuard → «+» → «Импорт из файла или архива» → выберите файл в «Загрузках» → «Сохранить» → включите переключатель.

Как поставить на Android или Windows

Android: приложение Kotyara VPN, вход по логину и паролю — инструкция. Windows — инструкция.

Ссылку никому не пересылайте

В файлах ключи доступа. Один файл — один человек: передавайте только сам файл, адрес этой страницы оставляйте себе.
