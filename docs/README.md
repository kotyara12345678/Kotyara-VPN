# Инструкции Kotyara VPN (сайт)

Статический сайт: чистый HTML/CSS/JS, без сборки и зависимостей.
Открывается двойным щелчком по `index.html`, деплоится на GitHub Pages
workflow-ом `.github/workflows/pages.yml`.

## Какие картинки нужны

Складывайте файлы в **`site/assets/screens/`** ровно с такими именами — страницы
уже на них ссылаются. Пока файла нет, вместо него показывается аккуратная
рамка-заглушка с описанием, поэтому сайт не выглядит сломанным.

## Требования к скриншотам

- Формат **PNG** (не JPG — текст останется резким).
- Телефон — вертикально, 1080×2340 или больше.
- Телевизор — 1920×1080.
- Windows — 1920×1080 или окно приложения целиком.
- Никаких личных данных: логин, почту, имя сервера и ключи замажьте.
- Кнопку, о которой говорит шаг, можно не обводить: подпись под картинкой уже
  объясняет, куда нажимать. Если хотите — обведите красным, будет ещё понятнее.

## Как проверить

1. Откройте `site/index.html` в браузере.
2. Пройдите по всем четырём карточкам.
3. Кнопки **A− / A+** в шапке меняют размер текста — проверьте на телефоне.

## Как опубликовать

1. Запушьте папку `site/` в `main`.
2. В GitHub: **Settings → Pages → Source: GitHub Actions**.
3. После первого пуша workflow `Instructions site` соберёт и опубликует сайт;
   адрес появится в логе job-а `deploy` и в Settings → Pages.
