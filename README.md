# Kotyara VPN

**Твой кот. Твой VPN.**

Быстрый и простой VPN для Android: открывает YouTube, Telegram и любой другой
контент, шифрует трафик и не требует настроек — скачал, ввёл код, подключился.

---

## 📲 Скачать

**[Скачать APK →](https://github.com/kotyara12345678/Kotyara-VPN/releases/latest)**

Установочный файл для Android. Размер ~75 МБ, требуется Android 7.0 или новее.

---

## 🚀 Быстрый старт (4 шага)

1. **Скачай APK** по ссылке выше и открой файл на телефоне.
2. **Разреши установку** из этого источника, если Android спросит
   («Настройки → Разрешить») — стандартное предупреждение для файлов вне Google Play.
3. **Зарегистрируйся по инвайт-коду** — код выдаёт администратор при подключении.
4. **Выбери сервер и нажми кнопку питания** — статус станет «Подключено».

Пошаговая инструкция: [docs/INSTALL.md](docs/INSTALL.md)

## ❓ Частые вопросы

| Вопрос | Ответ |
|---|---|
| Не пришёл инвайт-код | Напиши администратору — коды выдаются вручную |
| Не появляется нужный сервер | Выйди из аккаунта и зайди заново по новому коду |
| Не подключается | Проверь интернет, попробуй другой сервер |
| YouTube/Telegram не открываются | Переподключись или смени страну в списке серверов |
| Как отключить VPN | Кнопка питания на главном экране |

Полный список: [docs/FAQ.md](docs/FAQ.md)
